# XLive 18

منصة عربية قيد التطوير للمقاطع القصيرة والصور والبث والتواصل، بواجهة RTL وتصميم مناسب للهواتف.

## الحالة الحالية

- واجهة أولية فقط: `index.html` و`styles.css` و`app.js`.
- بطاقات المحتوى المعروضة أمثلة تصميمية وليست منشورات أو ملفات حقيقية.
- نافذة تأكيد العمر واجهة تنبيه فقط وليست نظام تحقق عمر قانونياً.
- الحسابات والرسائل والرفع والبث والاشتراكات والمدفوعات غير مفعّلة.
- لا تُضف مفاتيح سرية أو كلمات مرور أو بيانات مستخدمين إلى هذا المستودع.

## قبل الإطلاق

1. اختيار استضافة تسمح صراحة بنوع المحتوى المقصود ومراجعة شروطها.
2. إعداد خادم وقاعدة بيانات للمستخدمين والجلسات والرسائل.
3. إعداد تخزين وسائط مناسب وآمن مع صلاحيات للملفات المدفوعة.
4. إضافة مراجعة إدارية قبل النشر، والإبلاغ والحظر وحذف المحتوى المخالف.
5. تنفيذ التحقق من العمر والموافقة وحقوق النشر وحماية البيانات.
6. اختبار الأمان والهواتف قبل نشر رابط عام.

## معاينة الواجهة

افتح `index.html` في متصفح حديث. هذه معاينة للواجهة فقط؛ لا تفعّل خدمات خلفية حقيقية.
